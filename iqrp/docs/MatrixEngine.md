# Matrix Engine

Dense and sparse linear algebra — `iqrp.app.math.matrices`.

## Core ops

Multiply, inverse, pseudo-inverse, transpose, det, trace, Kronecker, Hadamard,
row normalization, Frobenius norm, PD / symmetry checks.

## Decompositions

LU, QR, Cholesky, SVD.

## Eigen

`eig`, `eigh`, spectral radius, condition number, principal components.

## Sparse

CSR/CSC conversion, sparse multiply/add, sparsity ratio, identity.
