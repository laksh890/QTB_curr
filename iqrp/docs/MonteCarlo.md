# Monte Carlo Framework

`iqrp.app.math.stochastic.montecarlo` plus process / Markov utilities.

## Features

- Seeded `RandomStream` for reproducible parallel runs
- Crude Monte Carlo
- Antithetic sampling
- Control variates
- Thread-parallel Monte Carlo
- Expectation estimation helpers

## Related process tools

White noise, random walk, AR(1), Gaussian-process draws, correlated streams,
Markov stationary distributions, n-step transitions, empirical transition
matrices.
